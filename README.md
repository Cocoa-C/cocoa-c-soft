# cocoa-c soft

cocoa-c's official website

Built with Nuxt 4, Vue 3, and Nuxt Content.

## Getting Started

### Requirements

- Node.js 20.19+ or 22.12+
- pnpm

### Clone the repository

```bash
git clone https://github.com/Cocoa-C/cocoa-c-soft.git
cd cocoa-c-soft
```

### Install dependencies

```bash
pnpm install
```

### Start the development server

```bash
pnpm dev
```

Open the local URL printed in the terminal.

## Build

```bash
pnpm build
```

Preview the production build locally:

```bash
pnpm preview
```
